## 👋 About Me

I'm Muhammad Saqlain Arshad, an AI Engineer focused on building intelligent, scalable applications that bridge machine learning and software engineering. My work spans generative AI, retrieval-augmented generation (RAG), AI agents, model fine-tuning, automation and backend development. I enjoy taking ideas from experimentation through API design, testing and deployment.

**Current focus:** LLM applications · Agentic workflows · Parameter-efficient fine-tuning · AI system architecture
